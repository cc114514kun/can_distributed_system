# CAN应用层通信协议文档
项目：CAN分布式采集与边缘网关系统
版本：V1.0.0
日期：2026-08-31

## 1. 协议概述
本系统采用 **CAN2.0B 扩展帧** 实现多节点分布式通信。
下位机 STM32F103 采集节点主动周期上报传感器数据，
上位机 STM32F407 网关统一解析、校验、管理节点状态与故障。

协议设计目标：
- 保证多节点并发不冲突
- 具备数据校验防错
- 具备序列号丢包检测
- 可识别非法帧、错误帧、断线状态

## 2. 物理层参数
- 波特率：500Kbps
- 帧格式：CAN2.0B Extended 扩展帧
- 总线终端电阻：120Ω（两端必须焊接）
- 通信方式：节点主动上报，网关被动解析

## 3. 扩展帧 ID 分配规则（29bit）
本系统采用 **节点ID + 功能码** 分配帧ID，实现多节点区分

高16bit：设备节点编号
低13bit：功能子命令

当前唯一业务帧：**传感器周期上报帧**

## 4. 数据上报帧格式（节点 → 网关）
### 帧功能：周期上传温度、电压、按键状态
DLC = 8字节

| 字节 | 内容 | 说明 |
|------|------|------|
| 0 | Seq 序列号 | 自增序号，网关用于判断丢包、乱序 |
| 1 | KeyState | 按键状态 K1 K2 |
| 2~3 | ADC0 电压值 | 电位器电压（Q100 放大） |
| 4~5 | ADC1 温度值 | NTC 温度（Q100 放大） |
| 6 | Reserved | 保留字节 |
| 7 | CRC8 校验 | 整帧数据校验码 |

### 校验规则
- 校验范围：Data[0] ~ Data[6]
- 多项式：0x31
- 初始值：0x00
- 校验失败 → 网关上报 `FAULT_CAN_ILLEGAL_FRAME`

## 5. 网关处理逻辑
1. 收到报文先校验 CRC8，错误直接丢弃并统计错误帧
2. 校验通过比对序列号：
   - 序号跳跃过大 → 判定丢帧，记录丢包计数
3. 节点定时未收到数据 → 判定节点离线
4. 总线异常触发 BusOff → 自动复位总线并上报故障

## 6. 故障事件定义（协议层）
- FAULT_CAN_ILLEGAL_FRAME：CRC校验失败/非法数据
- FAULT_CAN_RX_OVERFLOW：接收队列溢出
- FAULT_CAN_BUS_OFF：总线进入BusOff状态
- FAULT_SENSOR_SEQUENCE：序列号异常丢包

## 7. 协议特点总结（面试可用）
1. 自定义应用层协议，区分多节点设备
2. 加入序列号实现**丢包检测、乱序检测**
3. 尾部 CRC8 保证**传输数据完整性**
4. 总线异常自动恢复，具备工业级容错能力
