# UART-CLI 串口维护接口文档
项目：CAN分布式采集与边缘网关系统
功能：设备调试、状态查看、故障读取、系统维护
波特率：115200，8N1

## 1. 概述
网关提供 **串口CLI人机交互控制台**，支持上位机下发文本指令，
设备返回标准化 OK / ERR 结果。

所有打印全部采用 **FreeRTOS消息队列异步打印**，
彻底解决多任务 printf 阻塞、乱码、卡死问题。

## 2. 指令总表（全部已实现）
| 指令 | 功能说明 |
|------|---------|
| GET_STATUS | 读取CAN总线统计状态（错误帧、BusOff次数） |
| GET_FAULT | 读取历史故障记录 |
| CLEAR_FAULT | 清空故障日志 |
| GET_VERSION | 读取软硬件版本、编译时间 |
| GET_NODE | 读取所有节点在线状态、序列号 |
| GET_SENSOR | 读取所有节点传感器实时数据 |
| GET_SYS | 读取系统队列、任务栈水位资源状态 |

## 3. 详细指令说明

### 3.1 GET_STATUS
功能：查询CAN总线运行统计
返回：
- 非法帧计数
- BusOff重试次数

### 3.2 GET_FAULT
功能：读取系统故障历史
输出内容：
- 故障时间戳
- 故障码字符串
- 故障节点ID
- 故障参数

### 3.3 CLEAR_FAULT
功能：清空故障管理器历史故障缓冲区

### 3.4 GET_VERSION
功能：读取整机版本信息
包含：
- 产品名称
- 硬件版本
- 固件版本
- 协议版本
- 编译时间

### 3.5 GET_NODE
功能：遍历所有节点
输出：节点ID、最新序列号、在线状态

### 3.6 GET_SENSOR
功能：批量读取所有节点实时采集数据
输出：电压、温度、按键状态

### 3.7 GET_SYS
功能：系统资源诊断
- 各任务栈剩余水位
- CAN接收队列占用情况

## 4. 交互协议规范
1. 上位机下发 **单行字符串指令**，回车结束
2. 设备返回以 `OK` 成功 / `ERR` 失败开头
3. 所有输出为 **异步线程打印**，不阻塞业务任务

## 5. 系统设计亮点
1. **解耦设计**：业务任务不阻塞，打印统一队列转发
2. **容错设计**：非法指令不崩溃、不卡死
3. **可维护性强**：现场无需重新编译即可排查故障
4. **全状态可视化**：总线、节点、传感器、故障、系统资源全覆盖

## 6. 应用场景
- 设备出厂调试
- 现场故障排查
- 系统稳定性检测
- 整机版本核验
